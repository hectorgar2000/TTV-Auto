# Música de fondo

Coloca aquí pistas de música libres de derechos (CC0 / dominio público)
en formato `.mp3` o `.wav`.

El pipeline elige una pista al azar y la mezcla a bajo volumen bajo la
narración. Puedes forzar una pista concreta con la variable de entorno
`MUSIC_TRACK=nombre_del_archivo.mp3`.

## Fuentes recomendadas de música CC0

- https://freemusicarchive.org (filtrar por CC0)
- https://incompetech.com (Kevin MacLeod, licencia CC BY)
- https://pixabay.com/music/ (licencia Pixabay, uso libre)

Para vídeos de lore/fantasía, busca pistas de tipo "epic orchestral",
"medieval ambient" o "celtic instrumental".
